# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or unexpected execution behavior:
1. Please do **NOT** file a public issue.
2. Email Anton Barinov at `55404783+Anton-Barinov@users.noreply.github.com` or open a private GitHub Security Advisory.

All reports are acknowledged and resolved promptly.
